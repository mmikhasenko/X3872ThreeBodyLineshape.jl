# x3872-3body — analytic continuation

**Goal:** Implement analytic continuation to compute correct discontinuity across the $D\bar D^*$ cut in the complex plane, enabling amplitudes on any sheet with explicit discontinuity handling.

**Stopping criteria / validation:**
- For points across the cut, the value above the cut and the analytically continued value below the cut agree (within tolerance).
- Numerical checks documented with example points and plots.

## Objectives
1) Compare current continuation algorithm(s) with an alternative path/contour.
2) Implement explicit discontinuity method tied to the $D^*$ pole.
3) Produce clear documentation (LaTeX) and a PDF report.
4) Integrate results into project NOTES and tracker updates.
